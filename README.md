<h2 align="center">AI Study Assistant </h2>

Your study assistant with AI. created with Langchain, Streamlit & RAG system. Supported with document like PDFs File.

## Installation

1. Clone this repository

```bash

git clone https://github.com/R1TGAMING/AI-Study-Assistant
```

2. Change to project directory

```bash
cd ./AI-Study-Assistant
```

3. Create venv with uv

```bash
uv venv
```

or if you don`t use uv

```bash
python -m venv .venv
```

4. Install `requirements.txt` depedencies

```bash
pip install -r requirements.txt
```

5. Run streamlit to localhost

```bash
streamlit run main.py

```
